## Why this matters

DevSpace exposes `/register`, `/token`, `/authorize` and `/mcp` to the internet
through a tunnel. The first three run JSON parsing and zod validation **before
any authentication**. The installed versions carry known high-severity
denial-of-service advisories on exactly that path (MCP SDK request-size and
validation memory exhaustion, zod oversized-collection memory exhaustion,
body-parser compressed-body DoS), plus a critical `proxy-addr` IPv4-mapped-IPv6
spoofing bug that matters as soon as a subnet-style `trust proxy` is used
(plan 013 does). Every fix is available within the current major versions.

```json
"overrides": {
    "body-parser": ">=2.4.0 <3",
    "fast-uri": ">=3.1.9 <4",
    "protobufjs": "7.6.6",
    "proxy-addr": ">=2.0.8 <3",
```

(`fast-uri` must stay on 3.x because `ajv` requires `^3.0.1`.) Then run `bun install`.

**Verify**: the Versions command above shows `@modelcontextprotocol/sdk@1.32.x` (x ≥ 2), `zod@4.6.x` (x ≥ 7), `express@5.3.x`, `body-parser@2.4.x` or later 2.x, `proxy-addr@2.0.8` or later 2.x, `fast-uri@3.1.9` or later 3.x (ignore the `@types/body-parser` and `@types/express` lines). - Typecheck fails because SDK or zod types changed.

- If `DEFAULT_MAX_REQUEST_BODY_SIZE` is not `4 * 1024 * 1024`, say so in the report. A `write_file` larger than about 100 KiB over MCP already returns 413, both before and after this bump.

## Maintenance notes

- The new `overrides` are floors, not pins, so future patch releases flow in automatically. Remove an override once its parent's own range excludes the vulnerable versions.
- The remaining highs (`undici` TLS/DoS, `brace-expansion`) need `@earendil-works/pi-coding-agent` ≥1.5 (it pins `undici 8.12.3` and `minimatch 11.0.3`). That is a 0.x→1.x API migration touching `src/pi-tools.ts`, `src/skills.ts`, `src/shell-environment.ts` and `src/cli.ts`. Plan it separately.
- Plan 013 enables `trust proxy = "loopback"` by default. That is only safe with `proxy-addr ≥ 2.0.8`, so this plan must land first.
